================================================================================
HOW TO USE
================================================================================

ENABLE WEBHOOK:
  1. Set N8N_WEBHOOK_ENABLED=true in .env
  2. Set N8N_WEBHOOK_URL=https://your-n8n-instance.com/webhook
  3. Set N8N_WEBHOOK_SECRET=<generated secret>
  4. Create webhook receiver in n8n
  5. Verify HMAC signature in n8n

ENABLE EMAIL (SMTP):
  1. Set EMAIL_ENABLED=true in .env
  2. Set EMAIL_PROVIDER=smtp in .env
  3. Set SMTP_HOST, SMTP_PORT, SMTP_USERNAME, SMTP_PASSWORD
  4. Set SMTP_FROM_EMAIL
  5. Test with: python -m pytest tests/test_email_service.py -v

ENABLE EMAIL (SENDGRID):
  1. Set EMAIL_ENABLED=true in .env
  2. Set EMAIL_PROVIDER=sendgrid in .env
  3. Set SENDGRID_API_KEY
  4. Set SMTP_FROM_EMAIL (must be verified in SendGrid)
  5. Test with: python -m pytest tests/test_email_service.py -v
